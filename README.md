👋 Hi there! I’m Nicholas Guilbeault, a software engineer with a passion for building. Currently, I’m a **Senior Research Software Engineer** at [NeuroGEARS](https://neurogears.org/) building real-time machine learning, computer vision, and hardware integration tools for scientific research.

🚀 I’m the core maintainer of the [Bonsai.ML project](https://bonsai-rx.org/machinelearning/) and contributor to the [open-source repository](https://github.com/bonsai-rx/machinelearning), integrating powerful ML functionality into the [Bonsai-Rx](https://bonsai-rx.org/) visual reactive programming language. I’m the author of [PointProcessDecoder](https://ncguilbeault.github.io/PointProcessDecoder/), a real-time Bayesian neural decoder for closed-loop experiments, and of [BonZeb](https://github.com/ncguilbeault/BonZeb), an open-source toolkit for kinematic tracking and closed-loop stimulation of small model organisms. I also maintain [bonsai-nix](https://github.com/ncguilbeault/bonsai-nix) for running Bonsai on Linux.

📚 Outside of coding, I'm often diving deep into the latest technology trends, sifting through internet archives, or experimenting with new tools and frameworks.
